00 — Principles

Four rules that hold it together

i.

Data first, chrome second

The interface disappears so the numbers speak. Restrained neutrals, one confident accent, generous whitespace around dense tables.

ii.

Tokens are law

No magic hex, no one-off px. Every value comes from a token. Change the token, change the product — nowhere else.

iii.

Hierarchy through type

Fraunces for moments that matter — titles, headline metrics. Geist for the working text. Weight and size, never colour alone.

iv.

Predictable, then delightful

Consistent spacing and states first; motion and polish only where they clarify. Every interaction earns its keep.

24 — Usage & mapping

Do, don't & where it lives

✓ Do
  • Reach for a token — --accent, --s-4 — never a raw value.
  • Keep one primary action per view.
  • Use Fraunces only for titles & headline numbers.
  • Right-align & tabular-align every numeric column.
  • Pair colour with an icon or label for status.
✕ Don't
  • Introduce new hexes or one-off spacing.
  • Stack two primary buttons side by side.
  • Set Fraunces on body or dense table text.
  • Signal meaning with colour alone (a11y).
  • Nest cards in cards — flatten the hierarchy.
